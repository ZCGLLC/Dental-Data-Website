# Enamel Intelligence

Research-stage website for a sensor-enabled dental implant platform.

The company name, tagline, email, navigation, calls to action, and model switch live in [`config/brand.ts`](config/brand.ts). Change them there.

## Scripts

```bash
npm run dev
npm run build
npm run lint
```

## Stack

Next.js, React, TypeScript, Tailwind CSS, Framer Motion, Three.js, React Three Fiber, Drei, GSAP, Lenis, and Lucide.

## 3D

The implant is procedural. Drop a replacement GLB at `public/models/smart-implant.glb` and follow `public/models/README.md`.

## Language

The site describes technology under development. Demonstration numbers are simulated. Nothing here is a claim of diagnosis, prevention, or regulatory clearance.
